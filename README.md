# unikey-midi

Para ejecutar este código hay que realizar los siguientes pasos.

* 1). Clonar el repositorio https://github.com/nextsigner/unikey
* 2). Compilar UniKey con Qt 5.14.2 Gcc 64bit
* 3). Ejecutar el binario unikey con el siguiente parametro: unikey -git=<esta repositorio>
* 4). Opcional: Si clonas este repositorio en la carpeta supondamos /home/usuario/unikey-midi
puedes ejecutar unikey -folder=/home/usuario/unikey-midi
